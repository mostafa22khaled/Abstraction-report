 🧠 Abstraction in Java

This project demonstrates the concept of **Abstraction** in Java, one of the core principles of Object-Oriented Programming (OOP).

It also shows how **Abstraction** is closely related to **Polymorphism**,
by allowing different classes to share the same interface (method signatures) while providing their own implementations.



 📌 What is Abstraction?

Abstraction is a process of hiding the implementation details and showing only the essential features of an object.

In Java, we achieve abstraction using:

- `abstract` classes
- `abstract` methods
